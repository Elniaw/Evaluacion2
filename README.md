# \# Evaluacion2

# 

# Programa en Python que calcula rutas entre dos ubicaciones usando la API de GraphHopper Directions. Fue desarrollado como parte de la Evaluación Parcial N°2 (CUY6142) para la consultora ficticia "API Ltda.".

# 

# \## Características

# \- Interacción con el usuario completamente en español.

# \- Distancias y tiempos con un máximo de dos decimales.

# \- Narrativa del viaje (instrucciones paso a paso) en español.

# \- Para salir, ingresar `s` o `salir` en cualquier pregunta.

# 

# \## Requisitos

# \- Python 3.8 o superior

# \- Librería `requests`

# \- Una API key de GraphHopper (https://www.graphhopper.com/)

# 

# \## Cómo ejecutarlo

# 1\. Instalar dependencias: `pip install requests`

# 2\. Ejecutar: `python GEOLOCALIZACION.py`

# 3\. Ingresar la API key cuando el programa la solicite.

# 4\. Elegir el medio de transporte (auto, bicicleta o a pie), el origen y el destino.

# 5\. Para terminar, escribir `s` o `salir`.
